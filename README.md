# ECHOES

ECHOES is a Flutter/Firebase beta for place-based memories: users attach photos and text to locations, places develop emotional aura summaries, and custodians can preserve memory spaces over time.

## Beta Status

- Flutter app, Firebase repositories, local repositories, Cloud Functions, Firestore rules, notification requests, crash reporting, analytics, caching, privacy paths, communities, custodianship transfer, and AR fallback/prototype flows are implemented.
- Local validation currently covers analyzer checks, unit/widget tests, beta integration tests, Cloud Functions tests, and Firestore rules tests.
- Remaining beta gate items require hardware or emulator sessions: Android/iOS smoke tests, permission prompts, offline/manual retry checks, ARCore/non-AR behavior, and target-device performance measurement.

## Prerequisites

Install these before running locally:

- Flutter stable with Dart SDK support for `^3.11.4`
- Node.js 22 for Cloud Functions
- Firebase CLI: `npm install -g firebase-tools`
- Android Studio with an Android emulator, or a connected Android device
- Xcode for iOS simulator/device runs on macOS only

Check your local toolchain:

```powershell
flutter doctor
node --version
firebase --version
```

## Local Setup

From the repo root:

```powershell
flutter pub get
npm install --prefix functions
npm install --prefix rules_test
```

Firebase native config files are intentionally not committed. For a real Firebase-backed run, place your local project configs in the normal FlutterFire locations:

- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`
- `macos/Runner/GoogleService-Info.plist`, if testing macOS
- `lib/firebase_options.dart`, generated by FlutterFire CLI

The app also supports local repository mode in tests through `EchoesApp()` without Firebase.

## Verify Before Running

Run the beta validation suite:

```powershell
flutter analyze
flutter test
npm test --prefix functions
npx firebase emulators:exec --only firestore "npm test --prefix rules_test"
```

The Firestore rules tests must run through `firebase emulators:exec`; running `npm test` directly inside `rules_test` will fail because no emulator host and port are available.

## Run Locally

List devices:

```powershell
flutter devices
```

Start an Android emulator if needed:

```powershell
flutter emulators
flutter emulators --launch <emulator_id>
```

Run the app on the selected device:

```powershell
flutter run
```

Run on a specific device:

```powershell
flutter run -d <device_id>
```

Run as a production-flavored build configuration:

```powershell
flutter run --dart-define=APP_ENV=production
```

For web smoke testing:

```powershell
flutter run -d chrome
```

For iOS on macOS:

```bash
open -a Simulator
flutter run -d ios
```

## Firebase Emulator Notes

The repo configures the Firestore emulator on port `8080` in `firebase.json`. To run emulator-backed checks:

```powershell
npx firebase emulators:start --only firestore
```

In another terminal:

```powershell
npm test --prefix rules_test
```

For a one-shot rules test, prefer:

```powershell
npx firebase emulators:exec --only firestore "npm test --prefix rules_test"
```

## Beta Smoke Checklist

Use this checklist on Android first, then iOS if available:

- Sign up and sign in.
- Grant or deny location permission and confirm the map state is understandable.
- Add a text memory with location captured.
- Add a gallery or camera image memory.
- Open a place detail sheet and memory detail sheet.
- Edit memory text/privacy and soft-delete a memory.
- Join a community and create a community-scoped memory.
- Initiate and accept a custodianship transfer.
- Toggle notification permission settings.
- Launch AR on an ARCore device and on a non-AR device to verify fallback.
- Enable airplane mode after loading nearby content and verify cached browsing behavior.
- Retry a failed image upload after network returns.

Record performance on a target mid-range Android device:

- App launch under 3 seconds.
- Memory/place load under 2 seconds.
- Location update under 1 second.
- AR mode at 30 FPS or better.
